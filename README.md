# Indigo Academy West — Официальный сайт школы (г. Бишкек)

Веб-портал для школы **Indigo Academy West** в г. Бишкек.

## Разделы сайта
- **Новости кампуса** — события школы, победы на олимпиадах, объявления учебной части.
- **Учительский состав** — преподаватели кафедр, предметы, аудитории и опыт.
- **Past Papers of IQA** — архив вариантов экзаменов *Indigo Quiz Assessment* с фильтрацией по предмету, классу и четверти.
- **Советы школе и Анонимный бланк жалоб** — открытая доска предложений с ответами администрации и полностью конфиденциальная форма жалоб без имени и публикации на сайте.
- **Соцсети и контакты** — Telegram, Instagram, YouTube, WhatsApp приёмной, 2ГИС Бишкек и TikTok.

## Две стороны сайта (Dual-Site)
- `/` — публичная сторона для учеников, родителей и учителей (без каких-либо кнопок или упоминаний админки).
- `/admin` — скрытая сторона для администрации школы (доступ по прямой ссылке и паролю).

## Запуск локально
```bash
npm install
npm run dev
```
Откройте в браузере `http://localhost:5173` (публичный сайт) или `http://localhost:5173/admin` (админ-доступ).
